Это учебное задание по теме введение в ООП на Python

Что здесь есть:
- Класс Seq для работы с биологическими последовательностями (белки и нуклеотиды)
- Класс FastaReader для чтения файлов в формате FASTA
- Определение типа записи (белок или нуклеотид) по стандарту IUPAC
- Генератор для работы с большими файлами
- Докстринги ко всем классам и методам
- UML-диаграмма классов
- HTML-документация, собранная через Sphinx
